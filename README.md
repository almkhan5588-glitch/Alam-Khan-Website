## GitHub Pages
1. Create a repository such as `alam-zeb-portfolio`.
2. Upload all files and the complete `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save and wait for the published website URL.
